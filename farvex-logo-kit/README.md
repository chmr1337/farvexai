# Farvex AI — Logo Kit

Brand colors: black #000000 · white #FFFFFF · cyan #22D3EE · slate #64748B

## svg/ (vector, infinitely scalable — use these wherever possible)
- farvex-logo-light.svg / farvex-logo-dark.svg — full lockup (mark + "Farvex AI"), text outlined so no font install needed
- farvex-mark-light.svg / farvex-mark-dark.svg — mark only, square
"light" = for light backgrounds (black mark) · "dark" = for dark backgrounds (white mark)

## web/ (transparent PNG)
- farvex-logo-{light|dark}-{400|800|1600|2400}w.png — lockup for headers, emails, decks
- farvex-mark-{light|dark}-{64…1024}.png — mark only

## social/
